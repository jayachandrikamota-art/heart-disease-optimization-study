# ❤️ Heart Disease Prediction using Optimization Algorithms

## About the Project

Heart disease is one of the leading causes of death worldwide. Early prediction helps in better medical decision making.

This project uses the Heart Disease UCI dataset to predict the presence of heart disease using Logistic Regression.  
Multiple optimization algorithms are implemented and compared.

---

## Dataset

Heart Disease UCI Dataset from Kaggle.

Features include:
- Age  
- Sex  
- Chest pain type  
- Resting blood pressure  
- Cholesterol  
- Fasting blood sugar  
- ECG results  
- Maximum heart rate  
- Exercise induced angina  
- ST depression (oldpeak)  

---

## Objectives

- Train Logistic Regression model  
- Apply different optimization algorithms  
- Compare convergence behavior  
- Evaluate model accuracy  
- Study constrained and unconstrained optimization  

---

## Optimization Methods

Unconstrained:
- Gradient Descent  
- Stochastic Gradient Descent  
- Mini Batch Gradient Descent  
- Momentum  
- Nesterov Accelerated Gradient  
- Adagrad  
- RMSProp  
- Adam  
- Newton’s Method  
- BFGS / L-BFGS  

Constrained:
- Equality Constraints  
- Inequality Constraints  
- KKT Conditions
